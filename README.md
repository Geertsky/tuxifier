# Ansible Collection - geertsky.tuxifier

This collection was created because of the need for a module to generate urls to rpms to realize the "Install minimal OS" task of the ansible-tuxifier role.

`ansible-tuxifier` role makes the bare metal installation of machines easy, completely controlled and parameterized. Additionally, it is faster and less error prone.

The documentation of the role can be found at [roles/ansible_tuxifier/README.md](roles/ansible_tuxifier/README.md).

The documentation of the module can be found in `ansible-doc geertsky.tuxifier.generate_minimal_install_urls_info`
